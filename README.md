# 还款管家

个人债务管理与智能还款规划平台，帮助用户全面掌握债务状况、制定最优还款策略、模拟债务重组方案。

## 功能概览

| 模块 | 功能说明 |
|------|---------|
| **财务总览** | 资产负债概览、财务健康度评估（风险等级/覆盖率/额度使用率/应急资金）、债务与资产分布饼图、还款趋势图 |
| **债务管理** | 债务 CRUD、Excel 批量导入/导出/模板下载、搜索与类型筛选、额度使用率可视化、移动端卡片列表适配 |
| **资产管理** | 资产 CRUD、资产类型分类（现金/存款/理财/基金/股票/其他）、流动性分级（高/中/低） |
| **收入支出** | 月收入/支出/额外收入设置、手动保存、实时预览可还款金额与预计还清时间、支出占比与还款能力指标 |
| **还款规划** | 三种策略模拟（雪崩法/雪球法/最低还款法）、策略对比表、还款趋势图、目标日期可行性分析、逐月明细 |
| **债务重组** | 最低还款滚动模拟、余额转移分析（手续费/促销期/回本周期）、债务整合方案对比、借新还旧场景与风险提示 |

## 技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | React 18 + TypeScript |
| UI 组件库 | Ant Design 5 |
| 图表 | ECharts 5 (echarts-for-react) |
| 构建工具 | Vite 5 |
| 数据持久化 | localStorage（前端存储，无需数据库） |
| Excel 处理 | SheetJS (xlsx) |

## 快速开始

### 环境要求

- Node.js >= 18
- npm >= 9

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

开发服务器启动后访问 `http://localhost:5173`。

## 设计规范

### 扁平化设计

- **卡片**：无边框无阴影，使用背景色区分层级（`#ffffff` / `#fafafa`）
- **图表**：纯色填充，无渐变无圆角
- **进度条/标签**：无圆角，无边框
- **动画**：仅保留 hover 背景色变化

### 设计令牌

所有样式通过 [theme.ts](src/styles/theme.ts) 统一管理：

| 令牌 | 说明 |
|------|------|
| `FONT` | 7 级字号体系（12px ~ 24px） |
| `FONT_WEIGHT` | 4 级字重（400 / 500 / 600 / 700） |
| `COLORS` | 语义化颜色（主色/成功/警告/危险/文字/背景） |
| `SPACING` | 6 级间距（4px / 8px / 12px / 16px / 24px / 32px） |
| `RADIUS` | 4 级圆角（4px / 6px / 8px / 12px） |

### 响应式

- 桌面端（md+）：表格视图，侧边栏可折叠
- 移动端（<md）：自动切换为卡片列表模式，搜索筛选全宽

## 核心功能说明

### 还款策略

| 策略 | 原理 | 适用场景 |
|------|------|---------|
| **雪崩法** | 优先偿还利率最高的债务 | 总利息最少，适合理性决策者 |
| **雪球法** | 优先偿还金额最小的债务 | 先获得成就感，适合需要正向反馈的人 |
| **最低还款法** | 仅偿还最低还款额 | 基准对比，展示最低还款的长期成本 |

### 债务重组模拟

| 方案 | 说明 |
|------|------|
| **最低还款滚动** | 模拟只还最低还款额时债务随时间增长的趋势，揭示"以贷养贷"的债务陷阱 |
| **余额转移** | 计算将高利率债务转移到低利率信用卡的净节省（手续费 vs 利息差），分析回本周期 |
| **债务整合** | 模拟申请新贷款一次性还清多笔债务，对比新月供与原方案总利息差异 |
| **借新还旧** | 常见场景参考表（信用卡还贷款/网贷还信用卡/账单分期/最低还款）及风险评级 |

### 数据管理

- 所有数据存储在浏览器 localStorage 中，无需后端服务
- 支持通过 Excel 批量导入债务（含模板下载、重复检测）
- 支持导出全部债务数据为 Excel 文件
